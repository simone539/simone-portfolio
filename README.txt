Simone Baidya Personal Portfolio

Files:
- index.html: website structure and content
- style.css: colours, layout, responsive design, dark mode and visual styling
- script.js: typing animation, scroll fade, progress bars and dark/light mode

How to use:
1. Extract the ZIP folder.
2. Open index.html in your browser.
3. Edit index.html for content changes.
4. Edit style.css for design changes.
5. Edit script.js for animation or function changes.
6. Replace Simone_Baidya_CV.pdf with your real CV using the same filename.


Project link editing:
- Replace each href="#" in the Projects section with your real GitHub, live demo, or report links.
- Replace images in the assets folder with your real screenshots using the same filenames:
  - forensic-escape-room.png
  - car-rental-app.png
  - pentest-lab.png


Education upgrade notes:
- Logo-style images are stored in the assets folder.
- Certificate placeholder PDFs are stored in the certificates folder.
- Replace each placeholder certificate with your real certificate PDF using the same filename.
- Replace logo-style images with official/approved logo files if you have permission to use them.
